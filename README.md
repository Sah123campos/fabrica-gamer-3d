# Núcleo Hardware: fábrica gamer em 3D

Site de uma página em Three.js. Ao rolar, a câmera atravessa os setores de uma fábrica de PCs gamer (recepção, engenharia, montagem, burn-in e expedição), segue o caminhão pela estrada e termina no quarto do cliente jogando.

As marcas são fictícias. Este é um site de demonstração.

**Site no ar:** https://sah123campos.github.io/fabrica-gamer-3d/

## Como abrir

Abra `index.html` no navegador. É preciso estar conectado à internet, porque o Three.js e as fontes vêm de CDN.

## Tecnologia

- Three.js r128
- Texturas geradas em canvas, sem arquivos de imagem
- HTML, CSS e JavaScript puros, sem build
